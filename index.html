Point & Shop

Picture symbols for finding things, answering questions and asking for help in grocery and clothing stores. Tap any symbol to show it full screen.

The symbols are for the shopper. The words under them are for store staff and caregivers.

Caregiver options

These pictograms were drawn for this page. They are not an official communication system like the ones speech therapists use.

If someone already uses a set of symbols, start with those and keep this page as a backup for stores. Saved symbols stay on this device.
